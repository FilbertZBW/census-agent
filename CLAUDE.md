# After any code change

Append a one-entry summary (what changed, what was verified) to
CHANGELOG.md under today's date. Keep entries factual and terse — one
line per change, no narrative or reasoning, just what happened and what
was verified (e.g. "3 existing unit tests green").

Do not edit REFLECTION.md or README.md unless explicitly asked to.
REFLECTION.md is a frozen snapshot the interviewer has already read —
never touch it.
